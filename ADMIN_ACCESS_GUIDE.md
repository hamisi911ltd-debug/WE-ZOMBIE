## What You Can Do Right Now (Phase 1)

### Courses Management
**URL**: https://immacurate.co.ke/admin/courses

#### View Courses
- See all 7 default courses in a grid
- Each card shows:
  - Course title (e.g., "Class B - Light Private Vehicle")
  - Category (e.g., "B")
  - Description
  - Fee breakdown:
    - Tuition: KES 12,600
    - PDL: KES 650
    - Test: KES 1,050
    - **Total: KES 14,300/=**
  - Duration: 6 weeks

#### Create New Course
1. Click "Add New Course" button (top right)
2. Fill in the form:
   - Course Title (required)
   - Category (required)
   - Description
   - Tuition Fee
   - PDL Fee
   - Test Fee
   - Duration
3. Total fee is auto-calculated
4. Click "Create Course"

#### Edit Course
1. Click the edit icon (pencil) on any course card
2. Modify any fields
3. Click "Update Course"

#### Delete Course
1. Click the delete icon (trash) on any course card
2. Confirm deletion
3. Course is archived (soft delete)

## Need Help?

### Common Issues

**Q: I can't see the admin panel**
A: Make sure you're logged in with the admin account (hamisi.911.ltd@gmail.com)

**Q: I get redirected to /dashboard**
A: Your account doesn't have admin role. Contact system administrator.

**Q: Courses not loading**
A: Check your internet connection and refresh the page.

**Q: Can't create/edit courses**
A: Make sure you have admin or instructor role.

### Support
If you encounter any issues, the system logs errors to the console. Check browser developer tools (F12) for error messages.
